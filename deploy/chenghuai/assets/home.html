  • ✓兼容主流调用之法

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["GATEWAY_API_KEY"],
    base_url="{{GATEWAY_ORIGIN}}/v1",
)

response = client.chat.completions.create(
    model="your-enabled-model",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(response.choices[0].message.content)

先将令牌保存为 GATEWAY_API_KEY 环境变量，再把 your-enabled-model 替换为已开通的模型名称。

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.GATEWAY_API_KEY,
  baseURL: "{{GATEWAY_ORIGIN}}/v1",
});

const response = await client.chat.completions.create({
  model: "your-enabled-model",
  messages: [{ role: "user", content: "Hello!" }],
});
console.log(response.choices[0].message.content);

CC SWITCH · 伍

借器之利

壹 · 添供给

新增供应商

启 CC Switch，点「Add Provider」，择「Custom」自定之式，为骋怀立一席之地。

贰 · 填三要

填入钥与门

API Key 填骋怀之钥（sk-chenghuai-…），Base URL 填 {{GATEWAY_ORIGIN}}，模型随君所好。

叁 · 一键启

保存之后，点「Enable」一键切换，重启终端或 CLI，骋怀之门豁然洞开。
